6 · Questions probables du prof

Pourquoi remplacer « - » avant de convertir en nombre ?

Sinon la conversion échoue (erreur). Vide → null, qui est accepté dans une colonne numérique.

Pourquoi des paramètres ? (TP 1.2, annexe)

Le chemin des fichiers est centralisé : sur un autre PC on change juste la valeur du paramètre (Gérer les paramètres), pas le code M de chaque requête.

Pourquoi désactiver le chargement des tables temporaires ?

Ce sont des étapes intermédiaires : on ne les charge pas dans le modèle pour l'alléger.

Jointure externe gauche, pourquoi ?

On garde toutes les lignes de la table de gauche (hébergements), même si le code postal n'existe pas dans la table de droite.

Mesure ou colonne calculée ?

Colonne : calculée ligne par ligne et stockée. Mesure : calculée à la volée selon les filtres du rapport (ex. moyenne de chambres).

Segment vs filtre ?

Segment = filtre visible sur la page pour l'utilisateur. Volet Filtres = filtre sur un visuel, une page ou tout le rapport (ex. exclure parc résidentiel).

M ou DAX ?

M (Power Query) = préparer/nettoyer les données avant chargement (ETL). DAX = calculs dans le modèle (mesures, colonnes calculées).
